# Capstone: A Basin's Water Story

**Level:** Intro · **Time:** ~60 min · **License:** CC-BY-4.0 · **Course:** [Introduction to Hydrology](../intro-to-hydrology/)

Synthesis capstone for the Intro to Hydrology course. Choose one of four CAMELS-US basins, compute hydrological signatures (Lyne–Hollick BFI, Richards–Baker flashiness, flow-duration curve) from five years of observed daily flow, run the TWI pipeline on a synthetic hillslope, then narrate the basin's water story through a 6-stage timeline. Every number comes from a cell or from CAMELS.

## What you'll learn

See the module itself — open it in AI-Hydro's HTML Preview panel.

## Requirements

Python packages: `numpy`, `matplotlib`. Real data are bundled; no network access.
