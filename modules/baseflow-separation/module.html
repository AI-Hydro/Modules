1 · Two flows, one stream

When it rains, two very different processes contribute to the stream at the same time:

⚡

Quickflow (stormflow)

Overland flow and shallow subsurface flow that responds rapidly to rain. Rises fast, peaks in hours to days, then recedes.

🌱

Baseflow

Groundwater seeping slowly from the saturated zone into the stream. Sustains the stream between storms. Changes on a seasonal timescale.

The Baseflow Index (BFI) is the fraction of total streamflow that is baseflow:

BFI = Σ baseflow / Σ total Q

A BFI near 1 means the filter assigns almost all of the flow to the slow component (for example a spring-fed stream); a BFI near 0 means almost all of it is classed as quickflow. The BFI depends on the filter and its parameter, so it is a filter output, not a measured groundwater fraction.

2 · The Lyne–Hollick digital filter

The Lyne–Hollick filter is a one-parameter recursive digital filter for automated baseflow separation (Nathan & McMahon, 1990; Ladson et al., 2013). For each time step t:

f(t) = α · f(t−1) + (1+α)/2 · [Q(t) − Q(t−1)]

b(t) = max(Q(t) − f(t), 0)  with  f(t) ≥ 0

where f(t) = high-frequency (quickflow) component  ·  b(t) = baseflow  ·  α = filter parameter (0 < α < 1)

The form used here runs 3 passes: forward → backward → forward, and each pass filters the baseflow left by the previous pass, not the raw series. The series is also reflected 30 steps at both ends so the recursion has a spin-up and the first and last days are not biased (after Ladson et al., 2013, who propose a standardised procedure including reflection of the series). The same implementation is used in every module of this course. The parameter α controls the smoothing:

α → 1

Quickflow decays slowly → more of each storm is classed as quickflow, baseflow hugs the slow trend. BFI falls (see the slider below).

α → 0

Quickflow decays quickly → baseflow follows Q more closely. BFI rises.

α = 0.925

A value commonly used for daily data (e.g. Nathan & McMahon, 1990).

Key insight α is a calibration parameter, not a physical constant, and it is defined per time step. If you want the same recession memory at a finer time step you need an α closer to 1, not lower: keeping the daily memory at hourly steps means αhourly = α1/24 (for the α on the slider: 0.9968).

Python Lyne–Hollick baseflow separation — α is updated by the slider above 
import numpy as np
import matplotlib
import matplotlib.pyplot as plt

alpha = 0.925  # ← drag the slider to change this

# ── SYNTHETIC 365-day hydrograph (deterministic, no random numbers) ──
days = np.arange(365)
storm_days = [12, 18, 34, 67, 98, 124, 155, 189, 210, 220, 251, 280, 305, 330, 352]
storm_amp  = [18, 11, 26, 9, 30, 14, 12, 24, 10, 20, 13, 17, 8, 11, 19]
uh = np.exp(-np.arange(20) / 4.0); uh /= uh.sum()
qf = np.zeros(365)
for d0, a0 in zip(storm_days, storm_amp):
    for k in range(20):
        if d0 + k < 365:
            qf[d0 + k] += a0 * uh[k]
b_true = 2.0 + 1.2 * np.sin(2 * np.pi * (days - 80) / 365)   # known baseflow
Q = b_true + qf

# ── Lyne–Hollick filter: 3 passes, each on the previous pass's baseflow ──
# Lyne–Hollick recursive digital filter, multi-pass with reflection; initial quickflow 0 for each pass.
# Each pass filters the baseflow of the PREVIOUS pass (forward / backward /
# forward; after Ladson et al., 2013), with the series reflected 30 steps at both ends.
#   f_t = alpha*f_{t-1} + (1+alpha)/2*(Q_t - Q_{t-1});  f_t = max(f_t, 0)
#   b_t = max(Q_t - f_t, 0)
# Single source of truth: shared/lyne_hollick.py (twin of lyne_hollick.js).
def lyne_hollick(Q, alpha=0.925, passes=3, reflect=30):
    Q = [float(v) for v in Q]
    n = len(Q)
    r = max(0, min(reflect, n - 1))
    cur = Q[1:r + 1][::-1] + Q + (Q[n - 1 - r:n - 1][::-1] if r else [])
    m, k = len(cur), (1.0 + alpha) / 2.0
    for p in range(passes):
        b, f = [0.0] * m, 0.0
        if p % 2 == 0:
            b[0] = cur[0]
            for i in range(1, m):
                f = max(alpha * f + k * (cur[i] - cur[i - 1]), 0.0)
                b[i] = max(cur[i] - f, 0.0)
        else:
            b[m - 1] = cur[m - 1]
            for i in range(m - 2, -1, -1):
                f = max(alpha * f + k * (cur[i] - cur[i + 1]), 0.0)
                b[i] = max(cur[i] - f, 0.0)
        cur = b
    return cur[r:r + n]


def baseflow_index(Q, base):
    sq = float(sum(Q))
    return float(sum(base)) / sq if sq > 0 else float("nan")
base = np.array(lyne_hollick(Q, alpha))
BFI  = baseflow_index(Q, base)
BFI_true = b_true.sum() / Q.sum()   # only knowable because the data are synthetic

# ── Plot ─────────────────────────────────────────────────
fig, ax = plt.subplots(figsize=(9, 4.2))
ax.fill_between(days, 0, base, color='#34d399', alpha=0.55, label='Baseflow (filter)')
ax.fill_between(days, base, Q,  color='#00A3FF', alpha=0.28, label='Quickflow')
ax.plot(days, Q,    color='#00DDFF', lw=1.6, label='Total Q')
ax.plot(days, base, color='#34d399', lw=1.1, ls='--')
ax.set(xlabel='Day of year', ylabel='Q (m³/s, synthetic units)',
       title=f'SYNTHETIC data · Lyne–Hollick  ·  α = {alpha:.3f}  ·  BFI = {BFI:.3f}')
ax.set_facecolor('#0f0f1e'); fig.patch.set_facecolor('#0a0a15')
ax.tick_params(colors='#7dd3fc'); ax.yaxis.label.set_color('#7dd3fc')
ax.xaxis.label.set_color('#7dd3fc'); ax.title.set_color('white')
for sp in ax.spines.values(): sp.set_color('#334466')
ax.legend(framealpha=0.4, fontsize=9, labelcolor='white')
plt.tight_layout()

print(f"α = {alpha:.3f}")
print(f"BFI (filter)   = {BFI:.4f}  ({BFI*100:.1f}% of flow classed as baseflow)")
print(f"BFI (true)     = {BFI_true:.4f}  (known only because this series is synthetic)")
print(f"Mean Q = {Q.mean():.2f}  |  Mean base = {base.mean():.2f}  (synthetic units)")
