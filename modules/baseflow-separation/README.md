# Splitting the Flow: Baseflow Separation

**Level:** Intro · **Time:** ~40 min · **License:** CC-BY-4.0 · **Course:** [Introduction to Hydrology](../intro-to-hydrology/)

Run the Lyne–Hollick digital filter interactively on a SYNTHETIC hydrograph with a known baseflow — drag the α slider to rewrite the live Python cell, compare filtered vs raw hydrographs side by side, and see why the Baseflow Index is a filter output rather than a measured groundwater fraction.

## What you'll learn

See the module itself — open it in AI-Hydro's HTML Preview panel.

## Requirements

Python packages: `numpy`, `matplotlib`. The hydrograph is SYNTHETIC (deterministic formula, no random numbers).

## Citation

Ladson, A. R., Brown, R., Neal, B. & Nathan, R. (2013). A standard approach to baseflow separation using the Lyne and Hollick filter. Australasian Journal of Water Resources, 17(1). doi:10.7158/13241583.2013.11465417
