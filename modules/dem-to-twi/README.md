# The Shape of the Land: DEM to TWI

**Level:** Intro · **Time:** ~55 min · **License:** CC-BY-4.0 · **Course:** [Introduction to Hydrology](../intro-to-hydrology/)

Compute the Topographic Wetness Index from a DEM step by step — click cells to trace D8 flow paths computed in code, run the full fill → D8 → accumulation → slope → TWI pipeline on a synthetic hillslope, explore a 3-D terrain, and compare elevation vs wetness with a wipe slider. Includes D8 vs D∞ and the effect of the slope floor and DEM resolution.

## What you'll learn

See the module itself — open it in AI-Hydro's HTML Preview panel.

## Requirements

Python packages: `numpy`, `matplotlib`. DEMs are SYNTHETIC; the real catchment map shows only the CAMELS gauge and boundary.
