# Runoff Generation: Infiltration Excess and Saturation Excess

**Level:** Intro · **Time:** ~40 min · **License:** CC-BY-4.0 · **Course:** [Introduction to Hydrology](../intro-to-hydrology/)

Two ways rain becomes runoff. Compute Green–Ampt ponding and infiltration on a SYNTHETIC soil column with a finite storage deficit, map which mechanism wins over rain intensity and deficit, watch the saturated area of a SYNTHETIC hillslope grow with storm depth, then compute event runoff coefficients from real CAMELS-US daily rain and flow for three basins and see why daily data cannot identify the mechanism.

## What you'll learn

See the module itself — open it in AI-Hydro's HTML Preview panel.

## Requirements

Python packages: `numpy`, `matplotlib`. Real data (CAMELS-US v1.2, water years 1996–2000: daily discharge, Daymet basin-mean precipitation and a few attributes for three basins) are bundled in `data/` with `data/PROVENANCE.json`; no network access.
