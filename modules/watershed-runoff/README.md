# The Watershed: Where Rain Becomes Runoff

**Level:** Intro · **Time:** ~40 min · **License:** CC-BY-4.0 · **Course:** [Introduction to Hydrology](../intro-to-hydrology/)

Define a catchment, trace D8 flow paths across a SYNTHETIC 3-D terrain (depression-filled, drop/distance routing, stream network from flow accumulation), then turn rainfall into runoff with an executable rational-method cell and an SCS curve-number cell.

## What you'll learn

See the module itself — open it in AI-Hydro's HTML Preview panel.

## Requirements

Python packages: `numpy`, `matplotlib` (for the two rain→runoff cells). Terrain and design inputs are SYNTHETIC.
