# Reading a Hydrograph

**Level:** Intro · **Time:** ~30 min · **License:** CC-BY-4.0 · **Course:** [Introduction to Hydrology](../intro-to-hydrology/)

Anatomy of a storm hydrograph — rising limb, peak, recession — with an interactive BFI explorer on a synthetic event, a curve-number storm-pair comparison showing non-linear runoff response, and a live Python cell that plots a real CAMELS-US water year (observed flow and basin precipitation) for three contrasting gauges.

## What you'll learn

See the module itself — open it in AI-Hydro's HTML Preview panel.

## Requirements

Python packages: `numpy`, `matplotlib`. Real data (CAMELS-US v1.2 water year 1996-10-01..1997-09-30) are bundled; no network access.

## Citation

Ladson, A. R., Brown, R., Neal, B. & Nathan, R. (2013). A standard approach to baseflow separation using the Lyne and Hollick filter. Australasian Journal of Water Resources, 17(1). doi:10.7158/13241583.2013.11465417
