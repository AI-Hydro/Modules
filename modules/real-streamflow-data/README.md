# Catching the Flow: Real Streamflow Data

**Level:** Intro · **Time:** ~45 min · **License:** CC-BY-4.0 · **Course:** [Introduction to Hydrology](../intro-to-hydrology/)

Load five real water years of USGS daily streamflow for four curated CONUS gauges from a bundled CAMELS-US snapshot (offline, with source hashes and QC flags). Plot the annual regime, spot flood days and rank annual maxima with Weibull plotting positions. An optional live NWIS cell reports failures instead of substituting data.

## What you'll learn

See the module itself — open it in AI-Hydro's HTML Preview panel.

## Requirements

Python packages: `numpy`, `matplotlib`; `dataretrieval` is needed only for the optional live NWIS cell (failures are reported, never replaced by synthetic data).
